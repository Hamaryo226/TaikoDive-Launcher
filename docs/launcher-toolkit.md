# ランチャーの追加機能

ライブラリ、プレイ記録、ツール、セットアップのタブと専用機能は削除しました。起動時はホームを開きます。

## 操作

| 番号 | 機能 | 操作場所 |
|---|---|---|
| 46 | ダウンロード再開 | 通信が切れた後、更新操作を再試行 |
| 45 | 適用前の追加・変更・削除一覧 | ランチャー設定 → 本体／Assetのアップデート |
| 28 | コーデのJSON共有と素材不足の確認 | 着せ替え → その他 → コーデ保存・共有 |
| 21 | 名前付きコーデの保存・読み込み | 同上 |

削除した専用機能は、初回セットアップ、ホームカードの配置設定、Discord・OBS連携設定、容量計測・キャッシュ整理、診断レポート、プレイカレンダー、リプレイ一覧・再生、楽曲の試聴・重複検査です。

保存済みのユーザーデータや本体側の連携設定ファイルは削除しません。

## 更新

本体・Assetの暗号化パッケージは、配信マニフェストのSHA-256をキーにキャッシュします。
HTTP Range対応なら途中から再開し、非対応なら最初から取得します。
サイズ・SHA-256と既存の暗号化パッケージ検証を通ったファイルだけを適用します。

設定・スコア等の保護対象は更新の対象外です。置き換えるファイルは更新前にバックアップします。
既存の更新履歴とバックアップも保持します。

配布スクリプトの `MinimumGameVersion` / `MinimumAssetsVersion` / `MinimumLauncherVersion` で必要な最低バージョンを指定できます。
未指定の旧マニフェストは引き続き使えますが、未指定であることは互換性の保証ではありません。

## コーデのデータ保護

コーデの取り込みは1MB・100件まで。形式・色・IDを検証し、共有ファイルでモデルの参照先を変更しません。
素材不足のコーデは一覧に保存できますが、適用できません。読み込んだコーデはプレビュー確認後に既存の保存操作で反映します。
コーデは `Info/TaikoDiveLauncher/outfits.json` に保存します。共有ファイルにはモデル本体を含めません。

## 検証範囲

ロジックのテストに加え、WindowsでのWinUIビルドと実画面確認が必要です。
ライト・ダーク・ハイコントラスト・狭い幅で、各画面を確認してください。
コーデの保存・読み込み、配信パッケージの更新プレビューと適用はWindows環境での確認対象です。
