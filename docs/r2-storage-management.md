# R2更新ファイルの自動容量管理

## 管理範囲と無料枠

対象は`taikodive`バケットの`launcher/`・`game/`・`assets/`です。現行のS3資格情報はこのバケットのオブジェクト操作に限定し、アカウント管理権限は追加しません。

[Cloudflare公式料金表](https://developers.cloudflare.com/r2/pricing/)によるStandard無料枠は10 GB-month/月、Class A操作100万回/月、Class B操作1,000万回/月です。転送量は無料です。容量は日ごとのピークの月平均で計算されます。Infrequent Accessには同じ無料枠を適用できないため、更新ファイルはStandardを使用します。

**この仕組みは保存容量の増加を抑制するもので、請求額のハード上限ではありません。** 他バケット、手動アップロード、外部の書き込み、過去の日次ピーク、公開URLへの大量アクセスによる操作回数は別管理です。Cloudflareの月間操作回数を取得する権限は既存のオブジェクト用資格情報にはなく、自動配信停止は実装していません。無料枠の完全保証や課金停止と呼ばないでください。

## 容量予算

単位は10進バイトです。複数リポジトリが同時に公開しても同じ余剰容量を取り合わないように、固定のチャネル別予算に分割します。

| チャネル | 容量予算 |
|---|---:|
| launcher | 500,000,000 bytes |
| game | 1,500,000,000 bytes |
| assets | 6,000,000,000 bytes |
| 合計 | 8,000,000,000 bytes |

公開前に、既存ファイルとアップロードに必要なピーク容量を確認します。容量不足や取得失敗の場合は公開を停止し、現行マニフェストを維持します。容量不足を理由に現行版を消したり、チェックを外して強行公開したりしないでください。

## 安全な保持と実行

- 現行マニフェストが指すパッケージを保護します。
- 直前版と48時間の猶予期間内のパッケージを保護します。
- 削除対象を認識できる更新パッケージ名に限定します。不明なファイルを勝手に削除せず、容量には含めます。
- 未完了multipartアップロードがある場合は新しい公開を停止します。定期保守は認識できる配布ファイル名で48時間を超えたものだけを中止し、再取得して消えたことを確認します。新しいものや不明な名前は保護し、ジョブを失敗状態にして通知対象にします。
- 旧マニフェストに保持履歴がない場合は、推測で旧版を消しません。新方式での最初の正常公開が保持履歴を確立した後、定期保守で世代整理します。
- 各リポジトリの公開と整理は同じconcurrency groupで直列化します。実行中のジョブはキャンセルしません。
- `maintain-r2.yml`は1日1回、そのリポジトリのチャネルのみを整理します。
- 手動実行は`apply=false`が既定で、読み取り専用の確認です。`apply=true`で安全な整理を適用します。
- ゲーム・Asset側はLauncherのレビュー済み40桁SHAから共通ツールを取得します。更新時は公開・保守双方のSHAを合わせてください。
- Actionsが無効、Secretが期限切れ、GitHub側の実行枠不足の場合、定期処理は実行できません。Actionsの失敗通知を有効にしてください。公開リポジトリの定期実行は無活動時にGitHubが停止する場合もあります。

手元で実行する場合も、必要なR2資格情報は環境変数で渡し、ログやコマンド引数に値を含めません。

```powershell
# 既定は読み取り専用
./tools/r2/Maintain-TaikoDiveR2.ps1 -Channel assets
# 計画を確認して適用
./tools/r2/Maintain-TaikoDiveR2.ps1 -Channel assets -Apply
```

## 可視性と旧版の移行

Launcherリポジトリは現在publicを維持します。現行クライアントはR2を直接読みますが、旧クライアントはGitHub Releasesの`launcher-main`を自己更新の入口にします。このミラーは移行完了まで必要です。

非公開化を行う場合は、旧ユーザーの移行確認、ゲーム・AssetそれぞれのGitHub Appによるprivate checkout検証、Webサイトの公開案内リンク更新を先に行います。Launcher EXEはゲーム一式のインストーラーではありません。既存の`TaikoDive.exe`と同じフォルダーに配置します。
