# どんちゃんの着せ替え

サイドバーの「着せ替え」で、3Dキャラ対応版 TaikoDive の衣装と色をユーザー別に設定できます。ゲームの次回起動時に反映されます。

## ユーザー別の保存

「設定するユーザー」で共通設定、またはユーザー1〜9を選びます。ユーザー番号は `Info/User.ini` の `1P_User_`〜`9P_User_` に対応し、実際の左右の太鼓とは別です。表示名を変更しても、同じ番号の衣装と色が残ります。未保存の変更を残したまま別のユーザーへ移る場合は確認します。

- 共通設定: 衣装・色の初期値と、モデルフォルダーを設定します。
- ユーザー1〜9: 選んだユーザーの衣装・色だけを保存します。モデルフォルダーは共通設定を使います。
- 未設定のユーザー: 共通設定を継承します。一度ユーザー別に保存すると、その衣装・色は共通設定の変更に影響されません。

ゲーム側ではタイトルのユーザー選択に追従し、ローカル2人プレイではエントリーした2人を区別します。ゴーストやオンライン相手の衣装は送受信・記録せず、従来どおり自分の見た目を使います。

## 衣装の選択

1. 「モデルの参照先」には配置済みのモデルフォルダーを指定します。モデルのコピー・インストールは不要です。相対パスはゲーム実行フォルダー基準です。
2. 「フォルダーの衣装一覧を読み込む」を押します。
3. 「あたま」と「からだ」を選びます。全身衣装にする場合は「全身きぐるみを使用」をオンにして選びます。
4. 「保存」を押します。

必須ファイルは `animations.glb`、`face/face_000000.png` と選択中の `head/<ID>.glb`・`body/<ID>.glb`、または `cos/<ID>.glb` です。名前は `costume_names.json` の `head`・`body`・`costume` を使用します。アイコンは `costume_head_icon/<ID>.png`、`costume_body_icon/<ID>.png`、`costume_icon/<ID>.png` から読みます。元のスキンのファイルは変更しません。

## 色の変更

「胴」「手足」「顔」「ふち」の項目をクリックすると、その部位のカラーピッカーがポップアップで開きます。16進数入力も使用できます。変更は直ちにプレビューへ反映し、画面上部の「保存」でファイルに保存します。「色を標準に戻す」で4部位を初期色に戻せます。衣装の色変更対応部分にだけ適用し、模様や目・口は変更しません。

## 設定ファイル

保存先はゲーム実行フォルダーの `Info/Chara3D.json` です。

```json
{
  "enabled": true,
  "modelsPath": "Info/Chara/Model",
  "parts": { "useCostume": false, "head": "0", "body": "0", "costume": "0" },
  "colors": { "body": "#00A7BE", "limbs": "#FFF6DE", "face": "#FF4125", "rim": "#FFF6DE" },
  "users": {
    "1": {
      "parts": { "useCostume": false, "head": "3", "body": "0", "costume": "0" },
      "colors": { "body": "#00A7BE", "limbs": "#32CD32", "face": "#FF4125", "rim": "#FFF6DE" }
    },
    "9": { "parts": { "useCostume": true, "costume": "4" } }
  }
}
```

既存ファイルの未知キーを保持し、保存前の内容を `Chara3D.json.launcher.bak` に残します。実行中のゲームへの保存、不正な色や衣装 ID、有効なモードに必要なファイルが不足した状態での保存を拒否します。プレイヤーは3D専用なので有効・無効の切り替えはありません。保存時は旧版との互換性のため enabled を true にします。

画面を移動するときに未保存の編集があれば確認します。保存後にゲームを再起動してください。旧版の TaikoDive はこの設定を読み込まないため、衣装・部位色対応版と組み合わせて使用してください。

## プレビュー

「着せ替え」画面では、ユーザー・衣装・色の変更後に保存前の見た目を自動更新します。animations.glb 内のアニメーションを一覧から選択し、全身衣装または頭と体の組み合わせ、部位色、輪郭をゲームと同じ描画処理で確認できます。「プレビューを更新」で再試行できます。

プレビュー対応版の `TaikoDive.exe` を `--character-preview <request.json> <preview.png>` で非表示起動します。要求と画像はOSの一時フォルダーに置き、終了時に削除します。ゲームの設定・スコア・モデルは変更しません。連続変更や画面移動では古い要求を取り消し、60秒でタイムアウトします。未対応の本体は起動せず更新案内を表示します。

プロフィールの旧キャラクター選択と連番プレビュー、起動構成のキャラ16bit化・アニメ読み込み間隔は削除しました。既存の `CharaType` と描画設定値は、他の項目を保存しても保持します。

プレビューは編集欄から独立して表示されます。広い画面では左にプレビュー、右に衣装と色を配置し、狭い画面ではプレビューを上に固定します。参照先は折りたたみ、通常の着せ替え操作を優先しています。

## 保存内容の復元

「保存済みに戻す」は未保存の編集を破棄し、現在の保存内容を読み直します。ツールバーのその他メニューにある「1つ前の保存を復元」は Chara3D.json.launcher.bak から選択中ユーザーの衣装と色を編集画面へ読み込みます。プレビューで確認して「保存」するまでファイルを書き換えません。モデルの参照先と他ユーザーは変更しません。

キャラ専用の間引き・16bit設定は定義と読み書きから削除しました。Setting.json の古い該当キーは次回保存時に除去し、その他の未知キーは保持します。

### アニメーション一覧

初期状態はアニメーションがオフで、通常ポーズの静止画を表示します。「アニメーション」をオンにすると、一覧からモデルに含まれるクリップを選んでループ再生できます。「一時停止」「再生」で切り替えます。アニメーションの選択と停止状態は衣装設定に保存しません。衣装・色を変更すると選択中の動きを再生成します。

モデル本来の秒数で再生し、ゲーム中のBPM連動速度とは異なります。通常は24fps相当、長いクリップは最大120フレームで全体の長さを保ちます。全フレームを同じ範囲で切り抜くため、ジャンプによって表示倍率が変わりません。保持するのは選択中の1クリップだけです。アニメーションプレビュー対応の本体が必要です。

静止画では1枚だけを生成し、編集後100msで更新を開始します。直近8通りの衣装・配色を画面内でキャッシュし、同じ見た目に戻した場合は再生成を省きます。生成中も前の画像を表示します。「プレビューを更新」または「フォルダーの衣装一覧を読み込む」でキャッシュを破棄するため、モデルを差し替えた場合は再読み込みしてください。アニメーション時の更新待ちは350msです。オン・オフはプレビューだけに作用し、ゲームの設定を変更しません。
