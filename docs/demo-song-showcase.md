# タイトル前の楽曲紹介を選ぶ

対応ランチャーの「楽曲 → タイトルの紹介曲を選ぶ」で「標準の紹介を使う」をオフにし、「紹介枠を追加」で1〜13個のボックスを縦に並べます。トグルがオンの間は紹介枠の設定を非表示にします。
各ボックスの「メイン曲」は大きく紹介する1曲です。「サブ曲は自動でおまかせ」は1曲目・2曲目それぞれで設定でき、オンの枠ではサブ曲の選択欄を表示しません。オフの枠では画面下の小さい4つに表示する「サブ1〜4」を2列×2行で手動選択します。左上がサブ1、右上がサブ2、左下がサブ3、右下がサブ4です。手動の選曲はおまかせへ切り替えても保持します。
曲の選択ボタンからSongs内の曲を検索・試聴できます。枠の左端中央にある目印をドラッグして並べ替え、メインとサブの組み合わせごと移動します。不要な枠は右上の赤いゴミ箱アイコンで外せます。「変更を保存」と保存状態はスクロールしても画面下に残ります。手動の枠はサブ曲を4つ選んでから保存します。保存後の次回ゲーム起動で反映します。
タイトル画面を表示しない起動構成では紹介も再生しません。

既存の `Texture/Demo/Animes/2/Anime.aup2`（または `Texture/00.Demo`）の動きと13枠を使用します。
13枠未満なら設定したボックスを順番に繰り返して13枠へ割り当てます。メイン曲と各ボックスのサブ4曲の曲名・副題・ジャンルをそれぞれ差し替えます。
おまかせは紹介アニメーションの読み込み時にSongsから有効な譜面を選び、その再生中は同じ組み合わせを使います。メイン曲を除いて4曲を選び、候補が4曲より少ない場合は候補を繰り返します。ほかに有効な曲がない場合はメイン曲を使います。サブ曲の音源は再生しません。
ロゴ・操作説明・注意画面は従来どおりです。

- 曲名・字幕・ジャンルはTJAから取得します。ジャンルが空なら親のbox.defを参照します。
- 音源はWAVE、再生位置はDEMOSTART、音量はSONGVOLとゲームの音楽／全体音量を使用します。
- 音源は紹介中の1曲だけ圧縮状態で保持し、枠の終了・タイトル移動時に停止・解放します。
- 元のaup2、PNG、OGG、TJAは変更しません。画像の差し替えテクスチャも紹介終了時に解放します。
- メイン曲の削除・音源不足はその枠を読み飛ばします。手動サブが使えない場合は、その位置をおまかせで補います。メイン曲が全枠で使えない場合や設定の破損・未対応版は標準紹介へ戻します。
- 「標準の紹介を使う」をオンにして「変更を保存」で元の紹介へ戻せます。各ボックスのメイン・サブ曲とトグル状態、順番を保持します。

## 設定形式

`Info/TaikoDiveLauncher/demo-songs.json` を本体とランチャーで共有します。
Asset・本体更新の保護対象ディレクトリ内に置き、ランチャーの保存時は `.launcher.bak` を残します。
ゲーム起動中の保存を拒否します。未保存の変更は画面移動前に確認します。

```json
{
  "version": 2,
  "enabled": true,
  "entries": [
    {
      "mainSong": "ジャンル/メイン曲/曲.tja",
      "autoSubSongs": false,
      "subSongs": ["ジャンル/サブ1/曲.tja", "ジャンル/サブ2/曲.tja", "ジャンル/サブ3/曲.tja", "ジャンル/サブ4/曲.tja"]
    },
    {
      "mainSong": "ジャンル/次のメイン曲/曲.tja",
      "autoSubSongs": true,
      "subSongs": []
    }
  ]
}
```

パスはSongs基準です。Songs自体の外部フォルダー接続は使用できますが、Songs配下のリンク、Songs外のTJAや音源は使用しません。
曲名・音源パスのスナップショットを保存しないため、譜面の修正は次の起動で読み直されます。
ランチャーは見つからない保存済み譜面も一覧に残し、勝手に削除しません。
旧version 1のsongs一覧も読み取れます。各曲をおまかせオンのボックスへ順番どおりに引き継ぎ、ランチャーで保存したときだけversion 2へ移行します。

## 文字の見た目

元の紹介PNGを基準にした専用の文字組みを使用します。`Texture/Fonts/FOT-OedKtrStd-E.otf`を直接読み込み、ゲーム全体のフォント設定を変更しても紹介の書体は変わりません。ジャンルの標準9種類は元の`Genre_Big` / `Genre_Small`画像を直接使用します。

メイン曲名と副題、次の4曲の曲名と副題は、それぞれ独立した文字サイズ・縁幅・行位置・字間を持ちます。副題がない曲でも曲名を上下に移動しません。文字の外形に合わせて字詰めし、英字や記号を含む曲名の重なりを防ぎます。幅の上限を超える長い曲名だけ、元PNGと同様に縦横比を保って縮めます。

PNGに焼き込まれた文字と実行時のGDI+描画にはアンチエイリアス等の差があるため、全画素の完全一致を保証するものではありません。元の書体を使えない場合は別書体へ置換せず、標準紹介へ戻します。

## テンプレートと所有権

`DemoSongTemplate`はaup2内の `Song_Main_0〜12.png` と `Song0〜12.ogg` のフレームから各枠を取得します。
`Song_Sub_行_枠.png`は次の曲の画像、`Genre_Big`は現在曲、`Genre_Small`のレイヤー順は次の4曲に対応します。
テンプレートがこの形式に対応しない場合は標準紹介へ戻します。

`AnimationTexture`のインスタンス限定の画像差し替えを使用し、通常のaup2再生や共用テクスチャを変更しません。
譜面は紹介に必要なヘッダーだけ読み取り、音声ファイルの書き換え・切り出しは行いません。
